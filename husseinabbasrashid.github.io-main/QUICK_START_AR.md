# 🚀 دليل البدء السريع - NovaStream Pro

## 📥 التثبيت السريع (5 دقائق)

### الخطوة 1: تثبيت Python
```bash
# تحميل Python 3.8+ من:
https://www.python.org/downloads/
```

### الخطوة 2: تثبيت المكتبات
```bash
pip install PySide6 yt-dlp
```

### الخطوة 3: تثبيت FFmpeg
```bash
# Windows (Chocolatey)
choco install ffmpeg

# أو تحميل يدوي من:
https://ffmpeg.org/download.html
```

### الخطوة 4: تشغيل التطبيق
```bash
python playlist_downloader.py
```

## ⚡ البدء السريع

### 1️⃣ أول استخدام

#### تحديد مجلد التحميل
```
1. افتح التطبيق
2. اذهب إلى الإعدادات ⚙️
3. اختر "تغيير المجلد"
4. حدد المجلد المطلوب
5. احفظ الإعدادات
```

### 2️⃣ تحميل أول فيديو

```
1. اذهب إلى صفحة التحميل ⬇
2. انسخ رابط YouTube
3. الصق في حقل URL
4. اختر الجودة المطلوبة
5. اضغط "🚀 Start Download"
```

### 3️⃣ تشغيل الوسائط

```
1. اذهب إلى صفحة المشغل 🎬
2. انقر نقراً مزدوجاً على أي ملف
3. استخدم HUD للتحكم
4. استمتع!
```

## 🎯 الميزات الأساسية

### 🎬 المشغل
- **تشغيل/إيقاف:** `Space`
- **تقديم/ترجيع:** `→` / `←`
- **رفع/خفض الصوت:** `↑` / `↓`
- **ملء الشاشة:** `F`
- **كتم الصوت:** `M`

### ⬇️ التحميل
- **جودة الفيديو:**
  - 💎 Max (أفضل جودة)
  - 🎬 4K (2160p)
  - 🎬 Full HD (1080p)
  - 📺 HD (720p)
  - 📺 SD (480p)

- **جودة الصوت:**
  - 🎵 MP3 320kbps
  - 🎵 MP3 192kbps

### 🔍 البحث
```
1. اذهب إلى Discover 🔍
2. اكتب كلمة البحث
3. تصفح النتائج
4. اختر تشغيل أو تحميل
```

## 🔧 حل المشاكل السريع

### ❌ لا يعمل FFmpeg
```bash
# تحقق من التثبيت
ffmpeg -version

# إعادة التثبيت
choco install ffmpeg --force
```

### ❌ فشل التحميل
```bash
# تحديث yt-dlp
pip install --upgrade yt-dlp
```

### ❌ لا تظهر المصغرات
```
1. تأكد من FFmpeg
2. أعد تشغيل التطبيق
3. امسح التخزين المؤقت (الإعدادات)
```

### ❌ تجمد الواجهة
```
1. أغلق وأعد فتح التطبيق
2. قلل عدد الملفات
3. امسح السجل
```

## 📱 الاختصارات المفيدة

### في المشغل:
| المفتاح | الوظيفة |
|---------|---------|

| `→` | +5 ثوان |

## 🎯 حالات الاستخدام

### 1. تحميل قائمة تشغيل كاملة
```
1. انسخ رابط القائمة
2. ✅ فعّل "Download Full Playlist"
3. اختر الجودة
4. ابدأ التحميل
```

### 2. استخراج الصوت فقط
```
1. الصق رابط الفيديو
2. اختر "🎵 Audio Only (MP3 320kbps)"
3. ✅ فعّل "Download Thumbnail"
4. ابدأ التحميل
```

### 3. البث المباشر
```
1. ابحث عن الفيديو
2. اضغط "▶ تشغيل"
3. سيتم البث مباشرة
```

### 4. إنشاء مكتبة موسيقى
```
1. حمّل ملفات MP3
2. ✅ فعّل "تضمين الصورة"
3. نظم في مجلدات
4. استمتع بالمكتبة
```
