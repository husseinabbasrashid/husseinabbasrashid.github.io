Add the following match block inside `match /databases/{database}/documents { ... }`
in Firestore Rules, before the final catch-all `match /{document=**}` block.
Keep the existing public_messages and reports rules.

    // Private rooms: the 12-character random room code is the entry password.
    match /private_rooms/{roomCode} {
      allow get: if request.auth != null;
      allow list: if false;
      allow create: if request.auth != null
                    && request.resource.data.keys().hasOnly(['createdBy', 'createdAt'])
                    && request.resource.data.createdBy == request.auth.uid;
      allow update, delete: if false;

      match /messages/{messageId} {
        allow read: if request.auth != null;
        allow create: if request.auth != null
                      && request.resource.data.keys().hasOnly(['name','text','imageUrl','createdAt','createdBy','clientId','pinned','replyTo','reactions'])
                      && request.resource.data.name is string
                      && request.resource.data.text is string
                      && request.resource.data.text.size() <= 1000
                      && request.resource.data.createdBy == request.auth.uid
                      && (request.resource.data.imageUrl == null || request.resource.data.imageUrl is string);
        allow update: if request.auth != null
                      && request.resource.data.createdBy == resource.data.createdBy
                      && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['reactions'])
                      || request.auth != null
                      && resource.data.createdBy == request.auth.uid
                      && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['deleted','deletedAt']);
        allow delete: if request.auth != null
                      && (request.auth.uid == resource.data.createdBy || request.auth.token.admin == true);
      }
    }

After adding the block, click Publish in Firebase Console. The app uses anonymous Firebase Authentication.

The room code is a secret that grants entry: share it only with people you want in the room. Anyone who gets it can read and send messages there. This is code-gated access, not end-to-end encryption.
